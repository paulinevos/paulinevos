## My name is Pauline 🦊👋

I'm a software engineer at [@mongodb](https://github.com/mongodb), where I work on open-source tooling in the PHP ecosystem. 

You may have seen me [speak at a conference](https://pauline-vos.nl/#/talks) (usually PHP, Symfony, or Laravel related conferences). And if you have, it was probably about version control.

#### 🌱 I'm a core maintainer on
- [`mongodb/mongodb`](https://github.com/mongodb/mongo-php-library) — The official PHP MongoDB Client Library
- [`ext-mongodb`](https://github.com/mongodb/mongo-php-driver) — The official PHP MongoDB Driver Extension
- [`mongodb/laravel-mongodb`](https://github.com/mongodb/laravel-mongodb) — Eloquent model & Query builder for Laravel
- [`doctrine/mongodb-odm`](https://github.com/doctrine/mongodb-odm) — The official PHP MongoDB ODM

I've also made contributions to other cool projects like SymfonyAI, LLPhant, imageio, and more.
